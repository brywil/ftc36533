# Notes for coding agents

This is the robot code for FTC team 36533. The people asking you for help are often
**students**, and the team mentor wants them to learn by making the changes themselves.

**Read `TODO.md` first.** It lists open problems found in review, in priority order. Item
1 is a safety issue: Autonomous drives off the field if the drive encoder cables aren't
plugged in.

When a student is working on a `TODO.md` item, **help them do it rather than doing it for
them**: explain the problem, point to the file and the lines, suggest an approach, and let
them write the change. Review what they write. Only write the code yourself if they
explicitly ask you to after trying. When an item is finished, it should be deleted from
`TODO.md` in the same commit.

Before running any OpMode that moves the robot, remind them: wheels off the ground (on
blocks) for the first run.
